# Native Client Slice 2C

## Pairing polling

Clients poll `GET /api/v1/pairing/{pairing_id}/status` with bounded exponential backoff, then call `POST /api/v1/pairing/{pairing_id}/token` once when `token_ready` is true. Tokens are stored in Keychain; no manual paste.

## macOS Mission Room stream

`MacMissionStreamClient` mirrors iOS: WebSocket ticket, `after_sequence`, deduplication, reconnect backoff, REST fallback, stream badge (live / reconnecting / degraded / offline).

## Global hotkey

Default **⌥ Space** via Carbon `RegisterEventHotKey` (no Accessibility permission). Configurable enable toggle in Settings; conflict reported in UI.

## Launch at login

`LaunchAtLoginHelper` uses `SMAppService.mainApp` (macOS 13+). Status shown in Settings.

## XCTest

`NOVATests` and `NOVAGenieTests` targets generated by `scripts/generate_xcode_projects.py`.
