# iPhone Action Button / Shortcuts

## App Intent

`NOVAListenIntent` — **Start NOVA Listening** (opens app, sets pending listen flag).

## Manual assignment

1. **Shortcuts** → **App Shortcuts** → **NOVA** → **Start NOVA Listening**
2. **Action Button** (Settings → Action Button) → choose the shortcut
3. Or add to **Control Center**

## Limitations

- No global always-on wake word on iPhone in this slice
- Intent requires opening the app (`openAppWhenRun`)

See [Native Client Slice 2C](NATIVE_CLIENT_SLICE_2C.md).
